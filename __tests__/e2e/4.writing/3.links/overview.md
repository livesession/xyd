# Overview

A [same-page anchor](#target-section) has no route to resolve, but it is still a
link.

A [rooted link](/guides/introduction) resolves through the router.

An [external link](https://example.com/docs) leaves the site.

A [mail link](mailto:hi@example.com) opens a client.

## Target section

The heading the same-page anchor points at.
