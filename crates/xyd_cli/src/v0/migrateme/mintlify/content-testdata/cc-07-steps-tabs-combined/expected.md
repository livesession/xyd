# Combined Guide

Follow these steps to get started.

:::steps{kind="secondary"}
. [icon="download" title="Install"] Install the `xyd-js` package.
. [title="Choose runtime"] Pick a runtime from the tabs below.
:::

Then select your platform:

:::tabs{kind="secondary"}
. [Pnpm](type=pnpm)
  Use `pnpm add`.
. [Bun](type=bun)
  Use **bun add** instead.
:::
